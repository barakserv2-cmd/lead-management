# ספקי עיבוד — הסכמי עיבוד מידע (DPA) — רשימת ביצוע

## מה בודקים בכל DPA (checklist)
- [ ] הספק מעבד רק לפי הוראותינו ולמטרותינו
- [ ] סודיות עובדי הספק
- [ ] אמצעי אבטחה (ISO 27001 / SOC 2 — Supabase, Vercel, Anthropic, Google יש)
- [ ] תת-מעבדים — רשימה + הודעה על שינוי
- [ ] הודעה על אירוע אבטחה תוך זמן סביר (עדיף ≤72 שעות)
- [ ] מחיקה/החזרה בסיום ההתקשרות
- [ ] מיקום עיבוד + מנגנון להעברה בינ"ל
- [ ] זכות ביקורת/דוחות

## העברת מידע לחו"ל — סיכום לתיק
תקנות העברת מידע 2001: מותר להעביר למדינה שמבטיחה רמת הגנה שאינה פחותה מישראל (EU — כן), או בהסכמת נושא המידע, או כשהמקבל התחייב בכתב לעמוד בתנאי הדין הישראלי (תקנה 2(4)).
- Supabase/Vercel EU → תקנה 2(1)/(8).
- Anthropic, Google, Vercel-as-company (ארה"ב) → DPA (2(4)) + אזכור במדיניות הפרטיות (הסכמה).
