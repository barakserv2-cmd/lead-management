# Migrations

הקבצים כאן הם מקור האמת לסכמה. הם מוחלים ידנית, קובץ-קובץ, על ה-DB בפרנקפורט:

```bash
node scripts/dryrun-migration.mjs supabase/migrations/000NN_name.sql   # בדיקה בטרנזקציה עם rollback
node scripts/apply-migration.mjs  supabase/migrations/000NN_name.sql   # החלה אמיתית
```

אין טבלת מעקב. לפני החלה, לבדוק ב-`git log` שהקובץ עוד לא הוחל, ולכתוב
מיגרציות אידמפוטנטיות (`IF NOT EXISTS`, `CREATE OR REPLACE`) כדי שהחלה כפולה
לא תזיק.

## מספור

מספר רץ בן חמש ספרות. כשלשני קבצים יצא אותו מספר (קרה כשעבדו במקביל), הקובץ
שנוסף מאוחר יותר קיבל סיומת `b` (למשל `00068_` ואז `00068b_`), כך שהסדר
הכרונולוגי נשמר גם במיון לפי שם. מיגרציה חדשה מקבלת את המספר הבא אחרי הגבוה
ביותר בתיקייה.

## הערות

- `00083_user_profiles.sql` מתאר טבלה שנוצרה ידנית בדשבורד לפני שהייתה תיקיית
  מיגרציות. על פרודקשן היא no-op.
- `messages` נוצרה ב-`00017_create_messages_table.sql` (עמודת `role`). גרסה
  ישנה עם `direction` שמעולם לא הוחלה הוסרה.
